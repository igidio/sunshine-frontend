La clave de acceso de chat te permite utilizar las herramientas en una aplicación externa (como Claude Desktop, Open WebUI, Cherry Studio y otros) e interactuar con el sistema con otros modelos de lenguaje.

Al generar una nueva clave de acceso, la clave de acceso anteriormente generada dejará de funcionar.
